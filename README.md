# Thai DSR — Dysarthric Speech Reconstruction

A project for reconstructing intelligible Thai speech from dysarthric
(motor speech disorder) input. The pipeline extracts speaker/content
embeddings from distorted speech, maps them toward a clean-speech target
representation, and resynthesizes a waveform — aiming to improve
intelligibility while preserving the speaker's identity.

## Project Structure

```
thai-dsr/
├── data/            # raw / clean / distorted audio and extracted embeddings
├── src/
│   ├── preprocessing/  # distortion generation, embedding extraction, manifest building
│   ├── models/         # encoder, mapper, vocoder architectures
│   ├── training/        # training loop and dataset loading
│   ├── inference/       # run trained pipeline on new audio
│   └── evaluation/      # STOI / PESQ / WER metrics
├── configs/          # YAML configs for data, model, and training
├── notebooks/         # exploratory / prototyping notebooks
├── results/           # checkpoints, generated audio samples, logs
└── docs/               # pipeline documentation and related work notes
```

## Installation

1. Clone the repository and enter the project directory:
   ```bash
   cd thai-dsr
   ```
2. Create and activate a virtual environment:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

> **Note:** `pesq` compiles a C extension on install — make sure build
> tools are available (Xcode Command Line Tools on macOS, Build Tools for
> Visual Studio on Windows) if installation fails.

## Data Setup

Place source recordings under `data/raw/`, and clean reference audio
under `data/clean/`. Distorted audio and extracted embeddings
(`data/distorted/`, `data/embeddings/`) are generated by the
preprocessing scripts and are git-ignored.

## How to Run

1. **Generate distortions and embeddings**
   ```bash
   python -m src.preprocessing.distortion
   python -m src.preprocessing.extract_embedding --input data/raw/<utterance>.wav
   python -m src.preprocessing.build_manifest
   ```
2. **Train the model**
   ```bash
   python -m src.training.train --train-config configs/train.yaml
   ```
3. **Run inference on new audio**
   ```bash
   python -m src.inference.run --input path/to/audio.wav --checkpoint results/checkpoints/<ckpt>
   ```
4. **Evaluate results**
   ```bash
   python -m src.evaluation.metrics
   python -m src.evaluation.wer
   ```

## Configuration

Config keys are documented inline in `configs/data.yaml`,
`configs/model.yaml`, and `configs/train.yaml`.

The training/inference wav2vec2 layer has one source of truth:
`configs/train.yaml` under `data.layer`. New embedding extraction saves only
that selected layer by default, using
`{utterance_id}_layer{NN}.npy`. Pass `--all-layers` only for layer-selection
experiments. Existing 25-layer caches remain compatible with
`scripts/select_layer.py`.

Train/validation/test assignments are made by utterance (never by augmented
row) and saved in `data/splits.json` for reproducibility.
