# Weighted-layer mapper experiment

New code only: `src/models/weighted_layer_mapper.py`, `src/training/train_mapper_weighted.py`, `scripts/run_weighted_mapper_smoke_detached.sh`, and `tests/test_weighted_layer_mapper.py`. The existing mapper class and checkpoints are not modified. No full training run is authorized or launched.

The frozen Thai XLSR encoder supplies its 25 `hidden_states`: index 0 is the pre-transformer representation (after feature projection/positional processing as defined by the model), and indices 1–24 are transformer outputs. A trainable vector of 25 zero-initialized logits gives uniform 4% softmax weights. The weighted sum is 1024-dimensional and feeds a freshly initialized instance of the original MapperModel. No old mapper weights initialize this model. The old checkpoint is read only for architecture/optimizer metadata and the separately evaluated baseline.

No extra per-layer normalization, scaling parameter, or auxiliary loss is introduced. This follows the basic trainable weighted-sum approach documented by [S3PRL/SUPERB](https://s3prl.github.io/s3prl/_autosummary/s3prl.nn.html). Uniform initialization gives all layers an equal initial opportunity; a concentrated layer-9 prior would slow discovery of alternatives. A larger final weight is diagnostic of this optimization, not a causal feature-importance score: layers are correlated and have different activation scales.

The reconstruction objective is the same masked L1 against the existing `compute_mel()` target. Metadata from `mapper_layer9.pt` supplies the unchanged 2-layer bidirectional LSTM (hidden size 512, dropout 0.1, projection hidden size 256), Adam LR 0.001, batch size 4, weight decay 0, and ReduceLROnPlateau (patience 5). Seed 42. The scheduler sees full validation mel loss after every completed epoch, as before. No gradient clipping is added; gradient norms and finiteness are audited. CPU training uses 4 threads and serial cache reads instead of 4 loader workers to control memory; this changes execution, not objective or batch size.

The 147/32/31 train/val/test utterance assignments are reused without rewriting the split file. Only 147 train + 32 validation distorted utterances are encoded; test audio is never read. Training and validation mel loss use the clean target's frame count, matching original training. Actual audio reconstruction uses distorted duration, matching original inference. Metrics use the existing waveform utilities, including simple common-length truncation, without DTW/alignment changes. This preserves comparability but does not resolve timing mismatch in the dataset.

The cache stores `(25, T_encoder, 1024)` arrays in FP16, keyed by utterance ID and distorted-file SHA256. Cache metadata pins encoder revision and manifest hash. FP32 weighted summation occurs inside the training graph; no mixed representation is precomputed. Mixing before linear temporal interpolation is mathematically equivalent to interpolating each layer first, with much lower batch memory. The estimated cache for all 210 severe utterances is 2.31 GiB; only train/val are cached. Starting free disk: approximately 13.9 GiB. Cache reuse avoids repeated encoder work in later manual runs.

The smoke is bounded at 300 updates (about 8.1 epochs), with STOI/PESQ at steps 0/100/200/300 on 8 evenly selected, fixed validation utterances. Full 32-utterance validation L1 is also evaluated each epoch. The existing layer-9 mapper is evaluated on those same 8 utterances through the same frozen UNIVERSAL_V1 vocoder. Its layer-9 input comes from the same FP16 cache, so the comparison shares quantization and encoding. The previous published test-set metrics are not the comparison baseline for this validation subset. PESQ failures are explicitly reported with valid counts rather than silently imputed.

Local detached execution (`nohup`, `setsid`, `disown`, and `caffeinate`) avoids packaging/uploading data to Colab. MPS is used only for the one-time frozen encoder pass; CPU handles the packed Bi-LSTM and baseline vocoder. The initial sandbox attempt could not access MPS and exited before training; the subsequent authorized run operates outside that sandbox. No Colab workflow is required for this smoke.

Two targeted tests verify uniform averaging, nonzero gradients into both logits and mapper, frozen input tensors, softmax normalization, interpolation equivalence, and padding isolation. They pass. Logs include per-step loss and gradients, per-layer weights/entropy/effective layer count, per-utterance metrics, generated WAV files, and before/after hashes of input checkpoints/configuration. `best.pt` stores the best validation-loss model; `final.pt` also stores optimizer/scheduler states. There is no resume option; future commands start a fresh model and reuse only frozen feature caches.
